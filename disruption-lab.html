Lab 17 · the three flow docs with no lab

Disruption, Completion & Doing the day

These are the flows that fire while the user is working. Every module is drawn; these three had never been, and between them they hold the app's only published duration for a sequence, its only automatic rescheduling, and two surprises it must keep quiet about.

All four findings below are the same shape as ones already fixed elsewhere in the set — a sheet specified in the doc that disclaims it, a rule about one thing written as a rule about another, and a durable fact with no log entry. That last one was ADR 0021, one lab ago.

The sheet, written twice

disruption.md closes with a "What this doc must NOT do" list whose first bullet is "This doc does not define the defer sheet. That is in 05-modules/tasks.md." It then specifies the defer sheet twice — once in §The shove, once in its own example — and the sheet it draws is not the one that doc defines.

Four options against four options, three of them the same. Which of the two is missing tells you what went wrong: the stranger in the list is an option from a different surface, one the same doc needs two sections later.
